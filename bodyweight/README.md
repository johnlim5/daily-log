# 自重トレーニング 3D ガイド

自重トレーニング10種目の動きを、関節アニメーション付きの3D人体モデルで確認できるWebアプリ。

## 機能

- **種目ビュー** — 選んだ種目の動作をループアニメーションで再生。ドラッグで360°回転・ホイール/ピンチでズームでき、あらゆる角度からフォームを確認できる。再生速度の変更・一時停止・フェーズのスクラブに対応。
- **筋肉ハイライト** — 種目ごとに使う筋肉がモデル上で色分け表示される(負荷が強いほど赤く)。右パネルの筋肉リストにホバーすると該当部位が光る。
- **トレーニング記録** — セット数×回数を記録(localStorageに保存)。
- **鍛え度マップ** — 記録の蓄積から「自分がどの筋肉をどれだけ鍛えてきたか」をヒートマップ表示。負荷は約14日で半減するため、継続が色に表れる。

## 収録種目

プッシュアップ / スクワット / プランク / 懸垂 / ランジ / ディップス / クランチ / ヒップリフト / バックエクステンション / パイクプッシュアップ

## 実行方法

サーバー不要。`index.html` をブラウザで開くだけで動作する(Three.js はローカル同梱)。

## 構成

| ファイル | 役割 |
| --- | --- |
| `js/data.js` | 種目データ(筋肉負荷・フォームポイント・ポーズ生成関数) |
| `js/figure.js` | 関節付き人体モデルの構築・ポーズ適用・接地補正 |
| `js/main.js` | シーン・カメラ操作・UI・記録/ヒートマップ |
| `js/three.min.js` | Three.js r147(同梱) |
