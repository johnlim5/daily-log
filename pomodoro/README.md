# ポモドーロタイマー

作業と休憩を繰り返すポモドーロ・テクニック用のタイマー。タブが非アクティブでも時間がズレない Web Worker 駆動で、音声アナウンス・デスクトップ通知に対応する。

## 機能

- **バックグラウンド耐性タイマー** — カウントダウンを Web Worker(`worker.js`)で回すため、タブを裏に回してもブラウザのスロットリングで遅延しない。リング表示と残り時間で進捗を確認できる。
- **音声アナウンス**(日本語 / `speechSynthesis`) — セッション開始・N分ごとの経過・休憩開始/残り時間・休憩終了を読み上げる。読み上げ間隔は設定で変更可(0で無効)。
- **デスクトップ通知＋ビープ音** — フェーズ切り替え時に通知と Web Audio のビープでも知らせる(通知は許可が必要)。
- **目標セッション数** — 目標数を設定するとドットで進捗を表示し、達成時に読み上げでねぎらう。
- **ロング休憩** — 4セットごとに長めの休憩へ自動的に切り替わる。

## 使い方

- **Start / Pause / Reset** ボタン、または **スペースキー** で開始・一時停止。
- **設定** — Work(作業分) / Break(休憩分) / Long(ロング休憩分) / Voice(読み上げ間隔・分) / Goal(目標セッション数、0で無制限)。

## 実行方法

サーバー不要。`index.html` をブラウザで開くだけで動作する。音声はブラウザの音量・サイレントモードの影響を受ける。

## 構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | UI・状態管理・音声/通知・設定 |
| `worker.js` | 別スレッドでカウントダウンを刻む(非アクティブタブでも非スロットリング) |

## 変更履歴

- **音声の頭切れ修正** — TTS エンジンが発話開始直後の数百ミリ秒を切り落とし、文頭にある分数(「25分」「5分経過」など)が聞き取れない問題を修正。無音のウォームアップ発話でオーディオを起動させ、本文の先頭に短いポーズを挿入することで、最初の語が常に最後まで聞こえるようにした。
